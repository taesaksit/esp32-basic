# 💡 LED Blink ด้วย ESP32

## 🔌 การต่อวงจร

| ESP32    | อุปกรณ์   |
| -------- | --------- |
| GPIO 2   | LED ขา + (ผ่าน R 220Ω) |
| GND      | LED ขา −  |

```
ESP32
  │
  ├── GPIO 2 ───────┐
  │                 │
  │              [220Ω]
  │                 │
  │              LED (+)
  │                 │
  │              LED (-)
  │                 │
  └── GND ──────────┘
```
